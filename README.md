# ドットテニス 3D

CPUと対戦する、スマホ向け (Android / iPhone / iPad) の 3D テニスブラウザゲーム (WebGL / three.js, PWA)。

## 遊び方
- 画面**左**: ジョイスティック(どこを触っても出現)で移動
- 画面**右**: スイングボタン
  - **短押し** → 弱振: ゆっくり短いボール
  - **長押し**して離す → 強振: 速く深いボール(ボタンが赤くなったら強振)
- ボールに当たった瞬間の**ジョイスティックの向き**へ打ち返す
- 黄色いリングは相手ボールの落下予測地点
- 1ゲーム (0/15/30/40/デュース) 先取で勝利。勝つと3秒後に自動で次のゲーム(ステージ)が始まり、負けるまで続きます。ステージが上がるほど CPU が強くなります。
- PC ではキーボード (矢印/WASD + Space) でも操作可能。

## 開発
```
npm install
npm run dev        # 開発サーバ
npm test           # ユニットテスト (vitest)
npm run build      # dist/ にビルド (sw.js を自動生成)
npm run test:e2e   # E2Eテスト (Playwright: Android / iPhone / iPad エミュレーション)
npm run art        # ドット絵 (public/sprites, public/icons) を再生成
```

## 公開 (GitHub Pages)
`main` ブランチに push すると `.github/workflows/deploy.yml` がテスト → ビルド → GitHub Pages へデプロイします。
初回のみ、リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定してください。

## PWA / アップデート
- `sw.js` はビルド毎に内容ハッシュ付きで生成され、全アセットをプリキャッシュします(オフライン動作)。
- 起動時・60秒毎・アプリ復帰時・オンライン復帰時に更新を確認し、新版はバックグラウンドでダウンロードされます。
- **ゲーム中(連勝中の自動次ゲーム含む)は更新を適用しません**。タイトル画面に戻ったとき、またはゲームオーバー後の「もう一度」押下時に適用(リロード)します。
